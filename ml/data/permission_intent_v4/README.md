# 权限意图数据 v4

本轮补足“需澄清”的四种情况：要求互相矛盾、数据来源未定、操作目标未定、作用范围未定。不能把全部歧义都当成“帮我弄一下”这样的模糊短句。

`train.jsonl` 是 1,248 条受控增强：从 32 项能力的正向动作和整类否定构造，覆盖允许／禁止交换，以及同一句式的矛盾／不矛盾要求。例如“禁止 A，却要求 A”和“禁止 A，却要求 B”分别对应澄清和执行 B。已明确禁止的 A 始终保留为 forbidden；澄清时 required 为空。

这些增强不是 1,248 个独立真实用户场景。审核方式是独立 AI 逐项审核有限原子字典和模板、再用独立程序全量核对组合标签。不能将 `template_reviewed` 解释为逐句人工审核。独立作者另写验证 224 条／112 族及保留测试 320 条／160 族，每族两种说法；独立 AI 再逐句复核。所有真人审核均为 pending。

训练还加入上一轮冻结的 1,601 条开发训练，验证保留原 399 条开发验证，合计训练 2,849／验证 623。上一轮 280 条题不加入训练或验证，仅作已知回归。32 项能力都保留，Android／HarmonyOS 映射字典不改。

验证和保留题各自覆盖全部 32 项能力；短句、完整条件句并存，采用普通用户说法。相同能力必然共用一些词，不能仅因此判泄漏；禁止规范化完全重复和同模板只换名字数字。

`lexicon.json`、生成器、训练、验证、保留数据的最终 SHA 由独立审核绑定，训练前写 `freeze_manifest.json`。训练程序只读训练和验证正文，保留题只校验字节哈希，直到最终权重、配置、词表、阈值、策略锁定。

开发校验及冻结入口：

```sh
python3 ml/prepare_intent_v4.py --require-review --freeze
```

审核表为 `train_review.csv`、`validation_review.csv`；评测后再生成保留题与逐条预测审核表。模型选择预算与九项预设实验目标见 `experiment_plan.json`。这些内部合成数据实验不能代替真实用户、人工审核和手机 NPU 验收。

`extension_plan.json`、`head_refit_plan.json`、`specialist_distillation_plan.json` 是原预算结束后、打开新保留测试前记录的验证驱动追加实验。它们不修改原数据或九项预设目标。`teacher_source.json` 固定公开 NLI 教师的 revision、文件字节数和 SHA；教师权重不属于部署模型。

`product_examples.jsonl` 为助手自行挑选的 25 条日常说明性案例，仅在锁定最终候选后展示新旧预测，不用于训练、选模型或宣称真实用户验收。它不是冻结训练／验证／保留测试的一部分。
