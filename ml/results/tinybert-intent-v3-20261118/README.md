# TinyBERT 对照补强训练 v3 · 2026-11-18

本轮重训和独立保留测试已完成。新版比旧版少报错，但只通过 8 项预设实验目标中的 1 项，**未通过验收，不替换现有 Demo**。第一个未解决的问题是 PyTorch 参考模型的语义泛化，尚未进入手机 NPU 验收。

新增 1,400 条／350 组对照数据，重点补强八项能力，保留全部 32 项输出。实际训练 1,601 条、验证 399 条；另 280 条由独立作者准备、在选择模型前冻结。数据经过作者自审和独立 AI 全审，人工审核仍全部 pending。结果是内部合成数据实验，不能作为真实用户准确率。

先比较两种分类头，再比较两个完整训练配置。当前分类头在短程对照中更好；从官方底座训练 35 轮的配置，验证综合指标 0.4783；从 v2 权重以较低学习率继续训练 25 轮的配置达到 0.6513。按验证集选择后者第 23 轮，随后才读取保留题。需要阈值 0.95、禁止阈值 0.90；策略要求 in_scope 概率至少 0.97。未据保留题结果继续训练或调参。

全能力状态与意图完全一致为 72/280；没有一组四条全部正确（0/70）。需要澄清的 20 条中，语义分类正确 0 条，策略实际要求澄清 3 条。高置信度仍会出错，例如“当前显示的两张联系人卡只对比，所有联系人写入都禁止”被预测为需要 contacts.write。

旧 295 条仅作已知回归：所需能力 F1 44.1%→45.1%，明确禁止 F1 54.9%→52.3%，多报样本 152→72，违反禁令 41→18。旧原始指标已精确复现。不能声称全部旧能力均改善。

## 已通过的工程检查

- 14 项三态标签、梯度、保存加载、分组对照、长度与拒绝策略检查。
- 最优权重保存再加载，输出完全一致；配置、词表、协议与权重共同锁定。
- 实际应用 WordPiece 与保存分词器在 2,900 条原话上完全一致（旧 1,500＋新开发 1,120＋保留 280）。
- 标准 ONNX 16/32/64 三档检查、CPU 数值与语义／策略决策对照通过，最大绝对 logit 差 1.1921e-5。
- 16 档没有能完整容纳的保留题，只检查 3 条无金标工程短句；32 档检查 193 条保留题＋3 短句；64 档检查全部 280 条＋3 短句。短句不计入准确率。

未编译新 OMC、未执行手机 NPU 验收、未更改现有 HAP。新协议是 32×3 能力 logits 和 4 类意图 logits，不能直接替换现有五标签模型文件。权重、词表、阈值和参考向量必须成套使用。

## 文件与后续

`evaluation/comparison_report.json` 保存全部对比及目标结果；`prediction_review.csv` 可逐条对照旧版、新版和标准答案；`reserved_review.csv` 将 70 组 a/b 指令并排显示；`error_analysis.json` 包含逐能力统计。所有人工审核栏均留空，状态为 pending。

本轮结果说明：续训比本轮从底座重新训练的配置更好，但新场景的漏识别、否定理解和澄清判断仍不足。下一轮优先人工确认真实用户指令和边界标注，补独立场景，并评估强中文教师模型的蒸馏；继续增加同模板改写不能替代这一步。当前 280 条已被评测和公开，下一轮只能作为已知回归，需另外准备独立保留题。

训练复现见[说明](../../../docs/tinybert-intent-v3-training.md)。大权重与三档 ONNX 位于下载包；本 Git 目录只保存轻量报告和审核表。下载位置与 SHA256 见 `downloads.json`。
